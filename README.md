# VYRA Games

Studio website featuring LEO: The Game, CM Vijay: Street Battle, Subway Surfers: Tamil Nadu and Dei Thambi.

## Run locally

```sh
npm install --legacy-peer-deps
npm run dev
```

## Production build

```sh
npm run build
```

Vercel uses the existing Vite configuration and publishes `dist`. Game artwork lives in `public/assets`, the page in `index.html`, and interactions in `src/studio.js`.

The LEO download dialog links to the studio’s shared Google Drive folder. Other game details link to the studio on Instagram for availability.
